# v1.15.0 — Journal v2: a run you can prove, from an independent review of v1.14.0

> **Status:** implemented — v1.15.0. Design date: 2026-09-16. Base: v1.14.0. Source: the Codex
> `gpt-5.6-sol @ ultra` review run through this skill on 2026-09-15/16 (five `gpt-5.6-luna`
> research subagents; report + digests were in the run's `.orchestrate/`), plus the run's own
> stalls, which became `shared-lane-hygiene.md`.

**Through-line:** v1.14.0 made a run *visible*; v1.15.0 makes it *provable*. The review's honest
critique was that the journal was auditable but not yet safe as a multi-run event log (no run
identity, sequence or corruption signal), that acceptance was not enforced (a stray checkmark
could flip a failed gate, `done` could bypass the ledger, `finish` bound to nothing), and that
liveness measured heartbeats instead of deliverables. Each of those is now a rule the script
enforces, not a sentence in a reference.

## Decisions

1. **Envelope + chain.** `schema`, `run`, `seq`, `ts`/`ts_utc`, `actor`, `prev`/`hash` (sha256 of the
   previous hash + the canonical line). The chain check compares each `prev` to the *recomputed*
   hash of the previous line, so one edited line breaks every line after it. Problems never hide
   events — views stay usable; `check` exits 1 and the header says so.
2. **One workspace, one run.** `board init` archives the previous run's workspace to
   `archive/<run-id>/`; `--resume` adds tasks to the current run. Second-run replay is gone.
3. **Migration is atomic and keeps evidence.** `board.jsonl` → `journal.jsonl` with a `.bak`;
   schema-less lines → v2 envelopes under a `legacy-<ts>` run id with `journal.jsonl.v1.bak`.
4. **Attempts, not resets.** Every implementer-tier dispatch increments the task's attempt; gate
   entries carry their attempt; the current attempt's gates are the only ones that count.
   `--reset-gates` survives as an alias with no meaning of its own.
5. **Explicit gates outrank parsing; parsing takes the first mark in text order.** `board gate
   --verdict` is the authoritative close; the findings-file parse is the fallback and a fail
   followed by a stray ✅ stays a fail.
6. **The ledger is written by `board done`, never bypassed.** A failed gate on the current attempt
   refuses it. `finish --gate pass` needs evidence, a clean `check --finish` (or `--force --reason`),
   and binds HEAD, the goal hash and the journal cursor; later work, a moved HEAD or a changed goal
   render `RUN COMPLETE (STALE)`.
7. **Two clocks.** Artifact time (deliverable mtimes) is liveness; heartbeat time (notes, events)
   is not. Stale covers every open stint, reviewers included.
8. **`REFUSED` is a status.** xcli lanes that return exit 0 + empty diff + a decline are journaled
   as such; `check` flags any xcli `DONE` with no commits.
9. **`board set` instead of editing.** Re-resolving a dimension is an event; the plan goes back to
   pending and the trail is kept in `run.md`.
10. **Resume is a receipt.** `board resume` ends with HEAD, the journal cursor and a receipt hash,
    probes every pointer, lists open-stint locators and cleanup, and marks unbacked claims
    `NOT_PROVEN`.
11. **Attention-first rendering.** Header attention strip, collapsed empty/done sections, `j/k`
    focus + `enter` for one card, `e` for all, `a` for attention-only; red only for failures;
    capability palettes (RGB/256/16), `NO_COLOR`, ASCII borders; sanitised text.
12. **Engine facts come from probes, dated.** Codex 0.154 (`gpt-6-astra`, `ultra`, no `-a`,
    `--worktree`, `resume` semantics, `--last` hazard), Grok 1.0.25, opencode 1.18, Hermes 0.18,
    Claude `--effort`. The launch/resume/quota discipline that every engine shares moved to its own
    reference, `shared-lane-hygiene.md`.

## Deferred (from the review, deliberately)

- Reserve-and-reconcile budgets and per-request cost accounting: journal receipts exist
  (`--tokens`, `--usage-file`, `turn.completed.usage`); a reservation step needs host-level cost
  facts the pack does not yet carry.
- Nested-run journals (a sub-orchestrator owning a child journal imported by the parent): the
  flight plan now *lists* nested roles instead of counting them; a child journal is the next step.
- Splitting `shared-token-economy.md` (over the review threshold): byte-identity gates make this a
  careful move; separate release.
