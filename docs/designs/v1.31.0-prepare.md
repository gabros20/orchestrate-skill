# v1.31.0 — prepare before dispatch, concurrency by default, research as source lanes

> **Status:** implemented — v1.31.0, 2026-10-13 (bundled with the worker work-log change).

## Problem

Three complaints from daily use, one root cause: the controller jumped straight into dispatch.

1. **It picked sequential too often.** Triage mapped "plan + mostly-independent tasks, sequential
   OK" to `staged` and labelled it the default; `parallel` needed "speed matters" on top of
   independence, and a long-context note pushed breadth back to `staged`. Most plans are written as
   numbered lists, so most runs became chains that were never chains.
2. **It never looked at the machine.** 116 of the author's 123 global skills carry
   `disable-model-invocation: true` — invisible in the model's skill list and unusable through the
   Skill tool — including the X, GitHub and YouTube research skills. The controller could not use
   tools it could not see, so research fell back to generic web search, and the user had to name
   every source in every prompt. A skill whose CLI was missing (`ytrelay`) went unnoticed.
3. **It never asked.** An unclear request was planned on guesses; the interview existed only as
   step 1 of `adversarial`, one question at a time.

## Decisions

- **Prepare is a step every run takes, cheap by construction.** Equip is a script (zero tokens);
  clarify fires only when a decision would otherwise be guessed; the scout only when the toolchain
  is undecided; Task 0 only when something changed. `prep=off` keeps the inventory, because it is
  free.
- **Equip before clarify.** What is installed reshapes the questions — a missing tool becomes a
  question in round 1, not a surprise in a lane.
- **Journal before decisions, plan after scope.** A kickoff archives any journal it finds, so `board
  init --goal … --prep auto` runs first, without the plan; triage queues the plan once clarify has
  settled the scope (`board init PLAN --resume`, which now merges with the recorded dimensions,
  keeps the run's branch and base, and puts an approved plan back to pending when it re-resolves
  anything — so the scout's approval never stands in for the run's).
- **The interview is Matt Pocock's `grilling`, embedded, not depended on.** Rounds over the frontier
  of open decisions, a recommended answer per question worded so "yes" accepts it, facts looked up
  rather than asked, done only on the user's confirmation. Embedded because a skill that names
  another skill does not reliably load it (the upstream's own FAQ reports exactly this bug), and
  because the user's machine may not have it. One technique, one place: adversarial, advisor and
  staged's pre-flight scan point at it.
- **Manual-only skills are files.** The inventory lists them; the controller reads their SKILL.md
  and briefs workers with the path. No host feature needed.
- **Free and local first; installs and paid tools are the user's call.** Proposed with the exact
  command, batched into a clarify round, verified after install. Never `sudo`, never credentials.
- **Track record over novelty in the scout.** A weeks-old tool with one viral post goes on the
  watchlist; a speed claim needs a benchmark you can open; the faster tool wins only a tie.
- **Concurrency is the default; sequence is a finding.** Triage classifies the kind, then reads the
  dependency graph: ≥2 domains → hierarchical, one domain with independent tasks → parallel waves,
  a true chain → staged. Parallel dispatches on readiness, never at wave barriers. The gates do not
  change with the shape — that was the trade the user asked for: speed without dropping criteria
  before code, ordered review, machine checks and the final gate.
- **Readiness means merged, for code.** A task that needs only an agreed interface starts at once;
  one that needs another task's code starts after that task's gate and merge, from a worktree cut
  at the integration tip — a return alone does not put code in anyone's tree. Criteria are written
  once, before the first implementer, never as a barrier per wave.
- **Hierarchical leads run the build play inside their domain** — interfaces first, criteria once,
  parallel waves in worktrees, spec then quality, merges into a domain branch — never implementing,
  even for a one-task domain; 2–7 domains per level; and the controller
  owns the cross-domain contracts and the integrator. Native nesting is real on the reference host:
  probed 2026-10-13 on Claude Code 2.1.296 (a subagent dispatched a nested subagent that reported
  the Agent tool too), which retires the old "subagents cannot spawn subagents" note.
- **Research is a play, not a tenth strategy.** `kind=research` runs `parallel` with source lanes,
  a synthesizer and a fact-checking final gate. Lanes are ungated by default (`review=off`) because
  the fact-check of the load-bearing claims is where verification pays; `review=factcheck` gates
  every lane when the stakes justify it. The user asked for fewer strategy names, not more.
- **The user's decisions stay the user's.** A clarify answer is journaled `--owner user`; the board
  refuses a revision without `--owner user`, and leads namespace their ids `D-<task>.<n>`.
- **Task 0 is the plan's first node**, run by a worker in the main tree with an allowlist of the
  approved commands; machine tools for the agents themselves are the controller's one-liners after
  a yes. Manual-only skills with side effects (send, post, deploy, buy, log in) need the user to
  name them.
- **The board renders what Prepare decided**: `kind · prep · decisions` (assumptions counted), the
  `tools` strip and tweak key `[10] tools`, researcher lanes instead of worktree workers.

## Not covered

- MCP servers are invisible to a shell script; the controller reads its own tool list for them.
- Whether a tool is *outdated* (installed but behind its registry) is not checked — it needs the
  network; `npm outdated -g` is the manual check.
- The scout's quality depends on the relay tools' cookies and tokens being valid; a lane that
  cannot authenticate returns BLOCKED with the fix (`! <login command>`), never a silent fallback.
- Native nesting depth beyond 2 was not probed; the hosts matrix records 5.
