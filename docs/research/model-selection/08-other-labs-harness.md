## Summary
- **Kimi K3 is reachable in every harness except Codex-native and Grok CLI**, and Kimi's own docs sanction three routes: Kimi CLI, Claude Code (`ANTHROPIC_BASE_URL=https://api.kimi.ai/coding/`, model `k3` / `k3[1m]` / `k3-256k`) and Codex CLI (custom `~/.codex/models.json` over the Responses API) [V S1,S3,S4]. Subscription (Kimi Code plan) or API key both work; the model ids are `k3`, `k3-256k`, `kimi-for-coding`, `kimi-for-coding-highspeed` [V S1].
- **`kimi-for-coding` is no longer K2.7 Code**: since the K2.8 rollout it is "upgraded in place" to **K2.8 Preview** ("close to K3", low/high/max effort, up to 1M ctx); `kimi-for-coding-highspeed` is still K2.7 Code HighSpeed (262,144 ctx, "6× speed, 3× quota usage") [V S1]. An older doc snapshot in (01) listed HighSpeed as up to 1M ctx; the current page says 262144.
- **Plan gating returns 401 not 403**: exceeding your tier (no K3, no 1M, no HighSpeed) returns HTTP 401; a mistyped HighSpeed id silently falls back to standard `kimi-for-coding` with no speedup [V S1]. K3 1M needs Pro / Allegretto and above; the new "Go" tier has no coding quota.
- **Cheapest credible workers (independent, AA Intelligence Index)**: MiMo-V2.6-Pro 46 @ $0.13; DeepSeek V4.1 Flash (max) 39 @ $0.27, 209 tok/s; Muse Spark 1.3 (max) 48 @ $1.60; GLM-5.3 (max) 45 @ $2.01; Kimi K3 (max) 44 @ $2.00; Qwen3.8 Max 45 @ $5.41 (worst cost/quality of the group); MiniMax M3 29 @ $0.51 [B S9, cross-checked with (03)]. Read "cost" as AA's cost to run its index, not per prompt.
- **Only GLM-5.3 and Gemini 3.8 Flash from these labs are on Terminal-Bench 4.0** (screenshot 2026-09-30): GLM-5.3 (max) in Claude Code 41.8% ±3.2 (rank 5 overall, ahead of GPT-5.6 Sol 37.3%); Gemini 3.8 Flash (high) in mini-SWE-agent 19.1% ±3.4. Kimi K3, DeepSeek V4.x, Qwen3.8, MiniMax M3 and Muse Spark are absent, so no independent terminal-work evidence exists for them [B S10].
- **Muse Spark 1.3 is a real harness-native option here**: Meta's own `muse` CLI is installed locally (Muse Code 0.1.0), with `--reasoning-effort none|minimal|low|medium|high|xhigh|max|ultra` and `muse exec` for headless runs [L S8]. It is closed-weights, 1M ctx, $1.25/$4.25 [V-sec S11]. Also reachable in Pi (`meta` provider, Responses API, `META_API_KEY` or Muse subscription OAuth) [V S6], opencode Zen (`opencode/muse-spark-1.3`) and Cursor (`muse-spark-1.3`) [L S7, V (01)].
- **Gemini is only well-served by `agy` and opencode/Pi/OpenRouter routes**; agy is not installed here, its model roster is contradictory across secondary sources (Gemini-only vs Gemini + Claude/GPT-OSS by plan) [P S13]. For orchestration, treat Gemini 3.8 Flash as a cheap, fast (242 tok/s) worker with contested reliability (05).
- **Vision/multimodal**: Kimi K3, K2.8 Preview, Qwen3.8-Max, MiniMax M3, Muse Spark 1.3, Gemini 3.8 Flash accept image (and video for most); DeepSeek V4 Pro and GLM-5.3 (non-Flash) are text-only, DeepSeek V4.1 Flash and GLM-5.3-Flash take images (01, 02). Kimi via Codex/Responses API: image yes, **video no** — extract frames with ffmpeg first [V S4].
- **Open-weight status verified on Hugging Face official orgs** (2026-09-30): Kimi K3, MiniMax M3, GLM-5.3 (`license:other`), DeepSeek V4.1 Flash / V4 Pro 0813 (MIT), GLM-5.3-Flash (MIT), Qwen3.8-2.4T-A95B all have official weights [V S12]. Whether hosted `qwen3.8-max` equals the 2.4T-A95B checkpoint is unknown.

Harness notes and quirks
- **Kimi CLI** [V S1,S2]: `--model/-m`, `-p/--prompt` (non-interactive), `--output-format text|stream-json` (only with `-p`), `--yolo` ("Ask When Needed"), `--auto` ("Never Ask"), `--plan`, `kimi login` (RFC 8628 device flow). **No thinking/effort flag is documented**; effort is set through model config or `/model` in-session. Provider types: `kimi`, `openai_legacy`, `openai_responses`, `anthropic`, `gemini`, `vertexai`; base URL `https://api.kimi.com/coding/v1`. The `SearchWeb`/`FetchURL` tools only work through the Kimi Code platform. Switching model mid-project invalidates the context cache (usage jumps); Kimi advises starting a new session.
- **Domain confusion** to watch: Kimi's docs use both `api.kimi.com` (CLI provider page, Pi source) and `api.kimi.ai` (Claude Code / Hermes pages); both appear in official docs; unverified which are equivalent [V S1,S2,S3,S5].
- **Claude Code + Kimi**: `ANTHROPIC_API_KEY=<kimi code key>`, `CLAUDE_CODE_EFFORT_LEVEL=high`; settings.json `env` overrides shell exports. K3 1M needs `k3[1m]` plus explicit compact/max-context env [V S3]. Effect on Claude Code tool schemas (Anthropic-messages API via Kimi's compatibility layer) not verified.
- **opencode**: local provider id for Zen is `opencode` (docs say `opencode-zen`; local wins) [L S7, V S16]. Zen prices can differ from first-party (Gemini 3.8 Flash 2× Google; Qwen3.8-max ctx 262K vs 1M on Go). `opencode-go` is the cheaper subscription bundle for open-weight models [L S7]. Kimi Code as its own provider requires `opencode auth login` -> "Kimi For Coding" and an API key from the Kimi Code Console (max 5 keys, shown once) [V S5].
- **Pi** (`--provider`, `--model <pattern>` accepts `provider/id` + optional `:<thinking>`, `--thinking off|minimal|low|medium|high|xhigh|max`, `-p/--print`, `--list-models [search]`) [V S6]. Provider ids seen in source: `kimi-coding`, `moonshotai`, `moonshotai-cn`, `meta`, `minimax`, `minimax-cn`, `deepseek`, `zai`, `zai-coding-cn`, `qwen-token-plan(-cn/-individual)`, `google`, `xiaomi(*)`, `opencode`, `opencode-go`, `openrouter`. Exact model ids per provider live in generated JSON not in the repo; run `pi --list-models kimi` to confirm before scripting. Pi source: K3 accepts tool-bearing system messages mid-conversation, K2.6/K2.7 do not; K2.7 Code is always-thinking [V S6].
- **Hermes**: `hermes chat --provider X --model Y`; documented ids `kimi-coding` (`KIMI_API_KEY`, example `kimi-for-coding`), `kimi-coding-cn`, `minimax`, `minimax-cn`, `deepseek`, `zai` (`GLM_API_KEY`), `alibaba` (`DASHSCOPE_API_KEY`), `gemini`, `openrouter` [V S17]. Locally only xAI OAuth and an Anthropic key exist, so all of these need new keys (02). Kimi's Hermes guide uses a `custom_providers:` YAML entry with `extra_body.reasoning_effort` [V S5].
- **Cursor CLI**: binary is `agent`/`cursor-agent`; `--model <m>`, `--list-models`, `agent models`, `--api-key`/`CURSOR_API_KEY`, `agent login`, `-p` with `--output-format text|json|stream-json`, `-f/--force` [V S18]. Cursor's pricing page lists Kimi K3 ($3/$15), GLM 5.3 ($1.4/$4.4), Gemini 3.8 Flash and 3.1 Pro, Muse Spark 1.3 [V S19, (01)]. The CLI model roster itself is not published; run `agent models` after fixing the broken local install (02). Third-party rows draw on the "Other Models" pool billed at API price.
- **Antigravity (`agy`)**: successor to Gemini CLI (shut down 2026-06-18) [P S13]. Roster is unverified: docs per (01) list Gemini 3.8/3.7/3.6 Flash and 3.1 Pro on all plans plus Claude 4.6 and GPT-OSS-120b on some; a Google forum thread titled "no models apart from Gemini 3.x available?" contradicts [P S13]. Cannot be run here.
- **Muse Code (`muse`)**: `muse exec` supports `--json` JSONL events, `--prompt-file`, `--api-key-stdin`, `-w/--worktree`, `--parallel-tool-calls`, `--permission-profile`, `--image` (repeatable), `--context-compaction-strategy`; interactive `muse` effort enum omits `max` but `exec` includes it (help texts differ) [L S8].
